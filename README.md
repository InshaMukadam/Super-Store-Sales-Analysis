#  Superstore Sales Analysis – Power BI Project

This Power BI report analyzes sales performance for a retail superstore. It helps identify trends, opportunities, and problem areas across products, customer segments, regions, and time periods. The dashboard supports data-driven decisions for improving profitability and operational efficiency.

---

##  Key Insights & Features

The report includes:

- **Sales KPIs**
  - Total Sales, Profit, Quantity Sold
  - Average Discount and Profit Margin
- **Product-Level Analysis**
  - Performance by Category and Sub-Category
  - Top & Bottom Selling Products
- **Customer Analysis**
  - Sales by Segment and Customer Name
  - High-value customer identification
- **Geographic Performance**
  - Sales by State and Region
  - Regional profitability mapping
- **Time Series Trends**
  - Monthly and Year-over-Year sales growth
  - Seasonality and sales cycles

---

##  Tools & Techniques

- **Power BI Desktop**
- **DAX** for measures and KPIs
- **Power Query** for data transformation
- **Data Modeling** using star schema
- Slicers, custom visuals, and interactive filters
